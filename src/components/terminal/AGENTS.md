# Terminal UI rules

- Terminal dashboard cards share live quotes and technicals through `src/components/terminal/terminal-market.tsx`: one cache, so the top cards and Market Watch never show different prices.
- Desktop chart keeps the drawing tools as a fixed left rail and a bottom bar (timeframes + UTC clock), TradingView style; phones toggle the rail from the top bar.
- Desktop Terminal follows the TradingView chart layout: full-height chart with the symbol chip + tools in the top bar, floating SELL/BUY on the chart, a bottom bar of date ranges (via `PERIOD_TIMEFRAME`), Paper Trading toggle and UTC clock, and a right icon dock (Watchlist, Ask Jenvu AI, Symbol overview). The Symbol overview (`TerminalSymbolHeader` + tabs + range returns + market cards; other tabs hide the chart with CSS so it stays mounted) is off by default and opened from the dock. The main chart defaults to Candles and offers Line (area, coloured against the previous UTC-day close), remembering explicit picks per browser. The Seasonals tab reads gold history (COMEX futures, daily 10y + monthly max) and headlines (Google News RSS) through `src/lib/terminal-overview.functions.ts`, fetched one after another with an in-memory cache; maths lives in `src/lib/chart/gold-history.ts` (tested): parallel bursts get rate-limited by the price source.
- Terminal opens in the light (white) look; only an explicit pick (side-rail switch or Settings → Preferences, saved as `pickedLook`) turns it dark: the old auto-saved `look` value is ignored so every account starts white.
- Dark chart palette is pure black (`#000000` background in `CHART_THEMES.dark`): user wants the chart fully black.
- Main Terminal instrument is XAU/USD (`XAUUSD`, trusted gold proxy history via `loadTerminalChart`, 2-decimal prices, 100 oz per lot, gold weekend closure); EUR/USD/BTC code paths stay but the UI defaults to gold. Why: user moved the product back from EUR/USD to gold.
- Only apply browser live ticks when their provider matches candle history; interbank EUR/USD history uses its own refreshed candles, not EURUSDT stream prices, to prevent artificial wicks from mixing forex and stablecoin feeds.
