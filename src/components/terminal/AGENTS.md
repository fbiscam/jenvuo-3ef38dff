# Terminal UI rules

- Terminal dashboard cards share live quotes and technicals through `src/components/terminal/terminal-market.tsx`: one cache, so the top cards and Market Watch never show different prices.
- Desktop Terminal follows the TradingView symbol-page layout: `TerminalSymbolHeader` (name, live price, tabs) on top; the Overview tab shows the main chart, range-return buttons (each switches the chart timeframe) and the market cards; other tabs hide the chart with CSS so it stays mounted. The main chart defaults to Candles and offers Line (area, coloured against the previous UTC-day close), remembering explicit picks per browser. Range-return buttons read the charted market's own history (Gold = COMEX futures, BTC-USD, EURUSD=X) and the header's "Moves …" box lists that market's movers; the Seasonals tab reads gold history (daily 10y + monthly max) and headlines (Google News RSS) through `src/lib/terminal-overview.functions.ts`, fetched one after another with an in-memory cache; maths lives in `src/lib/chart/gold-history.ts` (tested): parallel bursts get rate-limited by the price source.
- Terminal opens in the light (white) look; only an explicit pick (side-rail switch or Settings → Preferences, saved as `pickedLook`) turns it dark: the old auto-saved `look` value is ignored so every account starts white.
- Dark chart palette is pure black (`#000000` background in `CHART_THEMES.dark`): user wants the chart fully black.
- Chartable Terminal markets (Gold XAUUSD default, BTCUSD, EURUSD) with their labels, decimals, logos and weekend-close rule live once in `terminal-assets.tsx`; the server chart loaders already accept all three: one list keeps the pair switch, header and watchlist in step.
- Only apply browser live ticks when their provider matches candle history; interbank EUR/USD history uses its own refreshed candles, not EURUSDT stream prices, to prevent artificial wicks from mixing forex and stablecoin feeds.
- The desktop right panel (`TerminalWatchlist.tsx`, no own title bar; opened by the header "Technicals & News" toggle, which takes the Ask Jenvu look while open) follows TradingView's symbol overview for the charted market only: quote, 1D feed volume vs 30D average, calendar news, performance pills and seasonals from `terminal-overview.functions.ts` (`getGoldSeasonals` takes the asset), and a gauge from `technicalSummary` on daily candles; it reuses the Overview's query keys so no extra price-source bursts.
- Forex EUR/USD candles have no volume: the loader borrows Binance EURUSDT volume, falling back to Yahoo 6E=F futures volume because the published server is often refused by Binance.
- Desktop and mobile share IndicatorLibrary, with entries backed by indicator-specs or the existing SMC switches; presets restore existing defaults and never bypass plan/timeframe gates. This avoids decorative or nonfunctional indicator listings.
- Terminal and public Ask Jenvu share AskJenvuComposer for identical message-box styling while retaining separate services; Terminal keeps chart context, attachments, voice and history, with pointer-captured dragging and viewport clamping so its narrower panel stays reachable.
- Terminal display grid uses a bottom-layer day-grid primitive with UTC day boundaries and a Sunday reference break for weekend-close markets; it never changes candle timestamps or feed/session bucketing. This keeps wide background blocks independent of candle logic.
