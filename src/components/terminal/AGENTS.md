# Terminal UI rules

- Terminal dashboard cards share live quotes and technicals through `src/components/terminal/terminal-market.tsx`: one cache, so the top cards and Market Watch never show different prices.
- Desktop Terminal follows the TradingView symbol-page layout: `TerminalSymbolHeader` (name, live price, tabs) on top; the Overview tab shows the main chart, range-return buttons (each switches the chart timeframe) and the market cards; other tabs hide the chart with CSS so it stays mounted. The main chart offers Line (area, coloured against the previous UTC-day close) or Candles, remembered per browser. The Seasonals tab reads gold history (COMEX futures, daily 10y + monthly max) and headlines (Google News RSS) through `src/lib/terminal-overview.functions.ts`, fetched one after another with an in-memory cache; maths lives in `src/lib/chart/gold-history.ts` (tested): parallel bursts get rate-limited by the price source.
- Terminal opens in the light (white) look; only an explicit pick (side-rail switch or Settings → Preferences, saved as `pickedLook`) turns it dark: the old auto-saved `look` value is ignored so every account starts white.
- Dark chart palette is pure black (`#000000` background in `CHART_THEMES.dark`): user wants the chart fully black.
- Main Terminal instrument is EUR/USD (`EURUSD`, Binance EURUSDT candles with session-anchored buckets via `loadEurTerminalChart`, 5-decimal prices, 100,000 units per lot, forex weekend closure); gold code paths stay for the server/AI but the UI defaults to EUR/USD. Why: user moved the whole product from gold to EUR/USD.
