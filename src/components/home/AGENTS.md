# Home components

- The homepage (`src/routes/index.tsx`) renders the `Ent*` sections from `src/components/home/EnterpriseHome.tsx` plus the shared `AllInOnePlatformSection`, `GetStartedSection` and the "For developers" API section `DevApiSection.tsx` (right under the top cards, where the JX Bot feature cards used to be; those cards now live only on `/jx-bot`; code samples use the real Jenvu endpoint and real model ids, metrics derived from real facts, never invented traffic numbers); its Latest news cards come from the loader (`home-articles.ts`) and show each article's stored `image_url` (other pages use generated covers); older section files in `src/components/home/` are kept unused for quick rollback. Dashboard pages get the Platform look from the scoped `.jenvu-zoom-dashboard main` rules at the end of `src/styles.css`: restyle there once instead of per page.
