# Home components

- The homepage (`src/routes/index.tsx`) renders the `Ent*` sections from `src/components/home/EnterpriseHome.tsx` plus `EcosystemGridSection.tsx` (6×2 logo grid of platforms/models Jenvu really works with, replacing the unused `AgentSmarterSection.tsx`; never customer claims or invented user counts; `/platform` keeps the shared `AllInOnePlatformSection`), the shared `GetStartedSection` and the "For developers" API section `DevApiSection.tsx` (right under the top cards, where the JX Bot feature cards used to be; those cards now live only on `/jx-bot`; code samples use the real Jenvu endpoint and real model ids, metrics derived from real facts, never invented traffic numbers); its Latest news cards come from the loader (`home-articles.ts`, pinned to the four `HOME_ARTICLE_SLUGS` so auto-generated posts never replace them) and show each article's stored `image_url` (other pages use generated covers); older section files in `src/components/home/` are kept unused for quick rollback. Dashboard pages get the Platform look from the scoped `.jenvu-zoom-dashboard main` rules at the end of `src/styles.css`: restyle there once instead of per page.
- `HomeMetricsBar.tsx` is no longer on the homepage (kept unused); any stats must be checkable facts (no profit or win-rate claims).
- `BotStatsBar.tsx` (under `DevApiSection`) shows owner-set capacity/seat figures (framed as capacity, not usage), the HASEEB wordmark, and JX Bot rules from `mt5-licenses.ts`: never win rates or invented usage counts.
- `CosmicOfferHero.tsx` is the first homepage section: countdown runs to the end of the current month (Founding seats reset monthly) and the offer text uses only real plan facts (yearly 22% off), never invented discounts.
